# CodSoft Artificial Intelligence Internship

## Task 1 – Chatbot
This project is a simple rule-based chatbot developed using Python. It responds to user inputs using predefined conditions and provides basic conversational responses.

## Task 2 – Tic-Tac-Toe AI
This project is a Tic-Tac-Toe game where the user plays against an AI. The AI uses the Minimax algorithm to choose the best possible move.

## Task 4 – Recommendation System
This project is a simple recommendation system developed using Python. It recommends items based on the user's selected preferences.
